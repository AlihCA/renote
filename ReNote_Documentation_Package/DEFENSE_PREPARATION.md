# DEFENSE_PREPARATION.md

## Defense Questions and Suggested Answers

| Question | Recommended Answer |
| --- | --- |
| Why not Google Drive? | Google Drive stores files. ReNote organizes, summarizes, cites, shares, and controls access to academic resources. |
| Why not Google Scholar? | Google Scholar helps find published research. ReNote helps manage uploaded learning materials, files, summaries, and institutional resources. |
| Why not ResearchGate? | ResearchGate is researcher-centered. ReNote is learning-resource-centered for students, faculty, and institutions. |
| How does ReNote reduce information overload? | Through repository organization, folders, search/filtering, AI summaries, summary history, citation support, and trust labels. |
| How do you prevent misinformation? | ReNote separates Community Resources, Faculty Published, and Official Resources through trust labels and uploader identity. |
| How are Faculty/Institution accounts verified? | For MVP, they are manually configured by developers. In production, institutional email, admin approval, or ORCID integration can be used. |
| Why allow regular users to publish? | To support academic sharing while clearly labeling non-official uploads as Community Resources. |
| Why require login for AI summaries? | To control cost, prevent abuse, track summaries, and enforce file access permissions. |
| How will ReNote handle cost? | Through usage limits, file size limits, cached summaries, storage quotas, archiving, and institutional or subscription funding in production. |
| What are the limitations? | No semantic search, no full document search, no real-time notifications, no admin portal, manual verification in MVP, and automatic lifecycle is future. |

## Main Defense Line

ReNote is not just a file storage system. It is an academic knowledge management platform designed to help users organize, access, summarize, cite, and evaluate learning resources more efficiently.
